# 07｜四渡赤水

学习整理稿，尚未经过实盘验证。当前材料主要是行情讲解中的模型示意，尚不是完整的独立规则课。

## 核心思路

**上涨后的调整，不因一次反弹就判定结束；先分清反弹有没有过前高，再等对应的结构确认**。“四渡赤水”在这段讲解中，重点是调整后突破下降切线及后续确认，不是数够四次涨跌就成立。

## 先分清后续路径

这里的“次高”指再次上攻但没有超过前高；“新高”指超过前高。

- **反弹只到次高，随后再回落**：观察调整结构，画出下降切线，等待“四渡赤水”式的向上突破与确认。
- **再次上攻创了新高**：转而观察“二次新高”后的结构，不能直接套用前一种路径。
- **调整很短，直接连续上冲**：讲解称为“走捷径”，提醒跟踪小周期是否走弱；它不等于已完成充分调整。

这些是分析分支，不是未来走势只能三选一的保证。

## 四渡赤水先看哪些环节

1. **看前面的上涨与回调**：先固定观察周期、前高和调整区间，不能把不同周期的高低点混着比较。
2. **画下降切线**：随调整观察受压的高点，找出要突破的线。仍在切线下方时，一次上涨不足以确认结构已经转强。
3. **等向上突破**：讲解多次强调“没有突破，就没有这一模型的买点”，不能把预想中的突破当成已经发生。
4. **看突破后的回踩**：继续观察是否守住、是否重新转强。突破后回落并非自动成功，仍需后续价格确认。

## 边界

底背离可能继续背离，突破也可能失败；形态像反转，不等于反转已成立。

这段材料尚未给出统一的切线取点、突破幅度、回踩容许范围和失效标准。“二次新高”及“同步”的完整定义也需继续核对。整理时保留这些缺口，不把历史图上的顺利路径写成之后必然发生的结果。
