# 活动共同原则

**明确问题与参与基础 → 选择活动 → 参照最佳实践 → 按需学习知识 → 交付与核对 → 复盘改进**

- 每个活动说明目标、参与基础、所用资料、要做的事和可检查的成果。
- [最佳实践](../practices/README.md)提供方法，[知识](../knowledge/README.md)解释概念与机制；活动通过链接关联，不复制正文。
- 验收关注结论所依赖的事实、关键判断、证据及其限制，也记录尚无法确认的问题。
- 先小范围试跑，再根据反馈修订活动和相关内容。

具体题目确定后，在[活动目录](README.md)登记；未完成事项统一放入[待办](../README.md#待办)。
