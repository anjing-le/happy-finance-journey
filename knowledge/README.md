### 02｜K 线与市场结构

开盘、收盘、最高、最低、阴阳线、影线、高低点、趋势、震荡、支撑、压力、突破、跌破、回踩、反转……

目标：看懂价格正在干什么。

### 03｜量价时空

量、价、时间、空间；放量、缩量、量价配合、量价背离……

目标：理解价格运动背后的力量。

### 04｜多空思维

买方、卖方、主动买卖、供需、预期、情绪、套牢盘、获利盘、多空转换……

目标：从“看图”升级到“理解人在干什么”。

### 05｜筹码与资金

筹码分布、成本、筹码峰、集中/分散、套牢盘、获利盘、吸筹、洗盘、拉升、派发、庄散博弈……

目标：理解资金、持仓成本与参与者博弈。

### 06｜技术指标

MA / EMA、MACD、DIF、DEA、RSI、KDJ、ATR、金叉、死叉、超买、超卖、顶背离、底背离……

目标：知道指标如何产生、能告诉我们什么、不能告诉我们什么。

### 07｜经典技术理论

道氏理论 → 波浪理论 → 缠论。

再扩展：趋势理论、形态理论、均线体系、量价理论等。

目标：理解不同流派如何解释市场。

### 08｜技术体系融合

比较不同理论的共同点、矛盾点、适用场景和局限。

目标：不迷信任何单一理论，逐渐形成自己的市场观。

## 最终阶段：形成自己的体系

把前面的知识逐渐整合成：

市场环境 → 基本面 → 趋势 → 位置 → 量价 → 多空 → 筹码 → 技术信号 → 买卖逻辑 → 仓位 → 止损 → 止盈 → 风险收益比 → 复盘。

最终每笔交易都能回答：

1. 为什么买？
2. 为什么现在买？
3. 什么情况说明判断错了？
4. 判断错了最多亏多少？
5. 判断正确预计赚多少？
6. 这笔交易值不值得做？

## 学习方式

一个名词一个名词学，每一个都搞透。每个知识固定回答：

是什么 → 为什么存在 → 怎么形成/计算 → 怎么看 → 有什么用 → 有什么局限 → 实盘案例 → 与已有知识串联。

学习原则：

- 先词汇 → 再关系 → 再理论 → 再系统。
- 先理解市场 → 再尝试判断市场。
- 不背口诀，不迷信指标，不迷信任何理论。
- 最终目标：知道自己在干什么。
